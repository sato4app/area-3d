### area-3d - 地図上の指定領域を3D表示

地理院地図上の指定した領域を、3D表示

## 起動方法

ES6モジュール構成のため、ローカルサーバー経由で開きます。

```bash
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 画面構成

- 2D地図と3Dビューは画面全体に切り替えて表示。画面右上の［3D］ボタンで3Dビューへ、3D表示中は［2D］ボタンで地図に戻る
- 「3D表示」で3Dモデルを作ると自動的に3Dビューに切り替わる
- 設定は地図の上に浮かぶ「ファイル読み込み」「Area3D」の2つのパネル。どちらかの見出しをドラッグで2つまとめて移動、右上のボタンでそれぞれ折りたたみ
- パネルの折りたたみ状態はブラウザに記憶される

## 使い方

1. 中心マーカーをドラッグ（または緯度・経度を入力、地名検索）して中心点を指定。地図のタップ・クリックでは中心点は動かない
2. 横 x (m)・縦 y (m) を入力（100〜20000 m）→ 地図上に赤枠で領域を表示
   - 赤枠の4隅の四角いマーカーをドラッグすると、中心はそのままでサイズを変更できる（パネルの数値も追随）
3. ベース地図・重ねる地図・標高データを選んで「3D表示」
   - 重ねる地図はベース地図の上に半透明で重なる（例：ベース「写真」＋重ねる地図「標準地図」で、航空写真に登山道・等高線を表示）
   - 「重ねる濃さ」は2D地図・3Dビューに即時反映。地図の種類を変えたときは「3D表示」を押し直す
   - 標高データは 1m・5m・10m メッシュから選ぶ。データの無い所（水面など）はより粗いデータで補完（1m → 5m → 10m）
   - 1mメッシュは領域が横・縦とも500m以下のときだけ選べる（3Dの分割数の上限512で1m間隔を保てる大きさ）。1mを選んだまま領域を広げると5mメッシュに自動で切り替わる
4. 3Dビューの操作
   - 左ドラッグ：回転 ／ 右ドラッグ：移動 ／ ホイール：ズーム
   - マウス位置の標高・緯度経度を左上に表示
   - 下辺の中央に縮尺バーを表示（遠近法のため、画面下辺付近の地表での目安。視点を動かすと追随）
   - 「高さ強調」で起伏を1〜5倍に強調
   - 「画像保存」で表示中の3DビューをPNG保存

### GeoJSONファイルの表示（ファイル読み込みパネル）

- 「GeoJSONファイルを選択」で `.geojson` / `.json` を読み込み、2D地図と3Dビューに表示（複数ファイル可）。読み込むとその範囲へ地図を移動
- LineString は線、Polygon は塗りつぶした領域（穴あき対応）、Point は丸印で表示。色はファイルごと。地理院地図の作図データの色指定（`_color` など）や simplestyle（`stroke` など）があればそれを優先
- ルートの LineString は「開始点 → LineString の各点 → 終了点」をつないで表示。開始点・終了点は properties の `startPointGPS` / `endPointGPS`（無ければ `startPoint` / `endPoint` の ID と一致する Point 地物の `id` / `pointId`）から取る
- 3Dビューでは地表に描き込むため、線・領域が地形の起伏に沿って表示される。3D表示の前後どちらで読み込んでもよい
- 2D地図で地物をクリックすると属性をポップアップ表示
- 一覧のチェックで表示／非表示（2D・3Dとも）、ファイル名クリックでその範囲へ移動、×で削除

## 使用データ（国土地理院）

| 種類 | タイル | 備考 |
|------|--------|------|
| 標高 1mメッシュ | `dem1a_png` (z17) | 領域500m四方以下のみ。データの無い場所は5m・10mメッシュで補完 |
| 標高 5mメッシュ | `dem5a_png` (z15) | データの無い場所は10mメッシュで補完 |
| 標高 10mメッシュ | `dem_png` (z14) | |
| 地表の地図 | `std` / `pale` / `seamlessphoto` / `relief` / `hillshademap` | 領域サイズに応じてズームを自動選択 |
| 地名検索 | 住所検索API (`msearch.gsi.go.jp`) | |

## ファイル構成

```
index.html
css/style.css
js/
  main.js            UIと各モジュールの連携
  config.js          設定値（タイルURL・初期位置・上限値）
  geo.js             緯度経度 ⇔ タイル座標の計算
  tiles.js           タイル取得、標高PNGのデコード
  TerrainBuilder.js  標高グリッドと地表テクスチャの作成
  TerrainViewer.js   Three.js による3D表示
  MapSelector.js     Leaflet による中心点・領域の指定
  GeoJsonLayers.js   GeoJSONファイルの読み込みと2D地図への表示
  GeoJsonDrape.js    GeoJSONを3Dの地表に貼る画像に描く
  Layout.js          フローティングパネル・地図/3Dの切り替え
```

ライブラリ（CDN）：Leaflet 1.9.4、Three.js 0.160.0
