### area-3d - 地図上の指定領域を3D表示

地理院地図上の指定した領域を、3D表示

## 起動方法

ES6モジュール構成のため、ローカルサーバー経由で開きます。

```bash
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 画面構成

- 2D地図と3Dビューは画面全体に切り替えて表示。画面右上の［3D］ボタンで3Dビューへ、3D表示中は［2D］ボタンで地図に戻る
  - ［3D］ボタンを押したとき、まだ3Dが無いか、中心点・領域サイズが表示中の3Dと違えば、3Dを作り直してから切り替える（地図の種類・標高データなどほかの設定の変更では作り直さない。それは「3D表示」ボタンで行う）。視点の向きはそのまま（距離は領域の大きさに合わせて伸び縮み）。重なる部分のタイルはメモリにあるものを使う
- 「3D表示」で3Dモデルを作ると自動的に3Dビューに切り替わる
- 電池の消費を抑えるため、3Dは視点を動かしている間（慣性で止まるまで）と表示内容を変えたときだけ描画し、止まっている間と地図表示中は描画しない
- 3Dの描画解像度は画面密度2倍までに制限（高精細なスマホでも描く画素数を抑える）。「画像保存」のPNGもこの解像度になる
- 設定は地図の上に浮かぶ「指定領域の3D表示」「ファイル読み込み」「このアプリについて」の3つのパネル（上から順）。どれかの見出しをドラッグで3つまとめて移動、右上のボタン（−／＋）でそれぞれ折りたたみ
- パネルの折りたたみ状態はブラウザに記憶される。「このアプリについて」は最初は折りたたんだ状態
- 「このアプリについて」パネルには、使い方・よくある質問・バージョン情報・QRコード（このページのURL）を縦に並べて表示。各項目は最初は閉じた状態で、見出しをタップすると開閉（右端のマークが閉じているとき V、開いているとき ^）

## PWA

- ホーム画面に追加すると、アプリのように全画面で起動する（`manifest.json`、`icons/`）
- `service-worker.js` がアプリ本体とライブラリをキャッシュし、電波の無い所でも画面は起動する
  - アプリ本体（HTML・CSS・JS）はネットワーク優先（つながっていれば常に最新）
  - ライブラリ（CDN）はキャッシュ優先
  - 地理院タイル・住所検索はキャッシュしない（3D表示にはインターネット接続が必要）
- 取得した地理院タイルは、ページを開いている間だけメモリに取っておく（`tiles.js`。圧縮されたままのデータで合計40MBまで、`config.js` の `TILE_CACHE_BYTES`。超えたら長く使っていないものから捨てる）。コンパスで中心点を少し動かしたときなど、重なる部分のタイルは取り直さない
- アプリのバージョンは `service-worker.js` の `CACHE_VERSION` だけで定義する（「このアプリについて」もこの値を読み取って表示）
- 「このアプリについて」の［バージョン情報］を開くたびに更新版を確認する
  - いまのバージョン：ページを開いた時点のサービスワーカーに問い合わせた値
  - 最新版：サーバーの `service-worker.js` をキャッシュを使わずに取得し、`CACHE_VERSION` を読み取った値
  - 違っていれば「更新しますか？」の確認を出し、OK なら新しいサービスワーカーに切り替えてページを読み込み直す（キャンセルしても、開き直せばまた確認を出す）
- アプリ本体のファイルは、ブラウザの一時保存（HTTPキャッシュ）を使わずサーバーに確かめてから使う
  - 命名規則：`yyyy-mm-dd.n`（yyyy-mm-dd は更新日、n はその日の1から始まる連番）。例：`2026-11-09.1`、同じ日の2回目は `2026-11-09.2`
  - アプリ本体を更新したら必ず変える（古いキャッシュが消え、新しいファイルが使われる）
- ファイルを増やしたときは `service-worker.js` の `APP_FILES` にも追加する
- サービスワーカーは https または localhost でのみ動く

## 使い方

1. 中心マーカーをドラッグ（または緯度・経度を入力、地名検索）して中心点を指定。地図のタップ・クリックでは中心点は動かない
2. 横 x (m)・縦 y (m) を入力（100〜20000 m）→ 地図上に赤枠で領域を表示
   - 赤枠の4隅の四角いマーカーをドラッグすると、中心はそのままで、縦横同じ長さ（正方形）のままサイズを変更できる（一辺は中心からの東西・南北の距離の長い方の2倍。パネルの数値も追随）
3. ベース地図・重ねる地図・標高データを選んで「3D表示」
   - 重ねる地図はベース地図の上に半透明で重なる（例：ベース「写真」＋重ねる地図「標準地図」で、航空写真に登山道・等高線を表示）
   - 「重ねる濃さ」は2D地図・3Dビューに即時反映。地図の種類を変えたときは「3D表示」を押し直す
   - 標高データは 1m・5m・10m メッシュから選ぶ。データの無い所（水面など）はより粗いデータで補完（1m → 5m → 10m）
   - 1mメッシュは領域が横・縦とも500m以下のときだけ選べる（3Dの分割数の上限512で1m間隔を保てる大きさ）。1mを選んだまま領域を広げると5mメッシュに自動で切り替わる
4. 3Dビューの操作
   - 左ドラッグ：回転 ／ 右ドラッグ：移動 ／ ホイール：ズーム
   - マウス位置の標高・緯度経度を左上に表示
   - 台座の4辺の外側に縮尺バー（長さを示す線と「○○ m」）を表示。長さは短い方の辺の3割以下で切りのよい値（500m四方なら100 m）。図形と一緒に回転・拡大縮小するので、どの向きから見ても手前の辺で正しい長さがわかる
   - 台座の4面の壁に標高の横線と標高値（「○○m」）を表示。横線は10mごとに、壁のある所全体に地表との境界（壁の上端）まで引く（壁の上端の線で切り取るので地表からはみ出さない）。文字は重ならない間隔で付け（高さ強調1倍の500m四方なら20mごと、強調を上げると10mごと）、5本ごとの線（10mごとなら50mごと、20mごとなら100mごと）は太い黒線、ほかはやや淡い線にする。文字の所は線を切る。文字は各面で壁の上端が一番高い所に1列並べ、外側から見たときだけ見える。領域が広く線が詰まりすぎるときは間隔を20m・50m…に広げる
   - 右上（2D/3Dボタンの下）にコンパスを表示。文字盤の北が画面上の北の方向を指し、視点を回すと連動して回る。下に画面の上の方角（8方位）と方位角（北=0°、東=90°）を表示。文字盤を押すと、中心から押した位置の方向（画面上の向き）へ中心点を領域の20%（東西は横幅、南北は縦幅が基準）だけ移動し、視点の向き・距離はそのままで3Dを作り直す
   - 画面下部に「一辺」のスライダーを表示。100 m〜20 km を切りのよい段階（100・150・200・300・400・500・700 m、1・1.5・2・3・4・5・7・10・15・20 km）で選び、指を離すと縦横同じ長さ（正方形）にして3Dを作り直す（視点の向きはそのまま、距離は領域の大きさに合わせて伸び縮み）。パネルの横・縦と2D地図の赤枠も合わせて変わる。1mメッシュで500mを超えたら5mメッシュに切り替える
   - 「高さ強調」で起伏を1〜5倍に強調
   - 「画像保存」で表示中の3DビューをPNG保存

### GeoJSON / GPXファイルの表示（ファイル読み込みパネル）

- 「GeoJSON/GPXファイルを選択」で `.geojson` / `.json` / `.gpx` を読み込み、2D地図と3Dビューに表示（複数ファイル可）。読み込むとその範囲へ地図を移動
- GPX は GeoJSON に変換して表示：ウェイポイント（wpt）→ 点、ルート（rte）→ 線、トラック（trk）→ 線（セグメントが複数なら区切りのまま）。名前・説明・標高・時刻などを属性として持つ
- LineString は線、Polygon は塗りつぶした領域（穴あき対応）、Point は丸印で表示。色はファイルごと。地理院地図の作図データの色指定（`_color` など）や simplestyle（`stroke` など）があればそれを優先
- ルートの LineString は「開始点 → LineString の各点 → 終了点」をつないで表示。開始点・終了点は properties の `startPointGPS` / `endPointGPS`（無ければ `startPoint` / `endPoint` の ID と一致する Point 地物の `id` / `pointId`）から取る
- 3Dビューでは地表に描き込むため、線・領域が地形の起伏に沿って表示される。3D表示の前後どちらで読み込んでもよい
- 2D地図で地物をクリックすると属性をポップアップ表示
- 3Dで点（マーカー）をタップすると、名称（properties の name・名称・title・タイトル・pointId・id の順で最初にあるもの）を吹き出しで表示。吹き出しは視点を動かしてもマーカーに付いて動き、何も無い所のタップか×で閉じる。判定は各点の画面上の位置とタップ位置の近さで行う（22px以内、丸印が大きく見えるときはその半径まで）。ドラッグや2本指の操作はタップとみなさない
- 一覧のチェックで表示／非表示（2D・3Dとも）、ファイル名クリックでその範囲へ移動、×で削除

## 使用データ（国土地理院）

| 種類 | タイル | 備考 |
|------|--------|------|
| 標高 1mメッシュ | `dem1a_png` (z17) | 領域500m四方以下のみ。データの無い場所は5m・10mメッシュで補完 |
| 標高 5mメッシュ | `dem5a_png` (z15) | データの無い場所は10mメッシュで補完 |
| 標高 10mメッシュ | `dem_png` (z14) | |
| 地表の地図 | `std` / `pale` / `seamlessphoto` / `relief` / `hillshademap` | 領域サイズに応じてズームを自動選択 |
| 地名検索 | 住所検索API (`msearch.gsi.go.jp`) | |

## ファイル構成

```
index.html
manifest.json        PWAの設定（アプリ名・アイコン・テーマ色）
service-worker.js    PWAのキャッシュ
icons/               アプリのアイコン（192・512・180px）
css/style.css
js/
  main.js            UIと各モジュールの連携
  config.js          設定値（タイルURL・初期位置・上限値）
  About.js           「このアプリについて」ダイアログ（使い方・FAQ・QRコード・バージョン）
  pwa.js             サービスワーカーの登録
  gpx.js             GPXをGeoJSONに変換
  geo.js             緯度経度 ⇔ タイル座標の計算
  tiles.js           タイル取得（直近のタイルをメモリに保持）、標高PNGのデコード
  TerrainBuilder.js  標高グリッドと地表テクスチャの作成
  TerrainViewer.js   Three.js による3D表示
  Compass.js         3Dビューのコンパス（画面の上の方角）
  MapSelector.js     Leaflet による中心点・領域の指定
  GeoJsonLayers.js   GeoJSONファイルの読み込みと2D地図への表示
  GeoJsonDrape.js    GeoJSONを3Dの地表に貼る画像に描く
  Layout.js          フローティングパネル・地図/3Dの切り替え
```

ライブラリ（CDN）：Leaflet 1.9.4、Three.js 0.160.0、qrcode-generator 1.4.4（QRコードの項目を開いたときだけ読み込む）
